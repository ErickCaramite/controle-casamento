Sincronização por código de acesso

Configure a URL e a chave pública do Supabase uma única vez. Depois, use o mesmo código secreto nos seus dispositivos para acessar o mesmo planejamento, sem conta ou login.

Use um código longo, com pelo menos 16 caracteres. Ele funciona como chave de criptografia: quem não souber o código não consegue ler os dados, mas qualquer pessoa que o conheça poderá acessar o planejamento. Guarde o código com segurança; não há recuperação se você o perder.
